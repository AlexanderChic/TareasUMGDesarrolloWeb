# Proyecto SASS - Desarrollo Web

Este repositorio contiene las tareas realizadas en el curso **Desarrollo Web**.  
El objetivo principal fue aplicar **SASS/SCSS** para la creación de estilos más organizados, reutilizables y fáciles de mantener.

## Contenido del proyecto
- Uso de **variables** para colores, fuentes y tamaños.
- Implementación de **mixins** para estilos reutilizables (ejemplo: botones/enlaces).
- Estructura con **header, main y footer** adaptados con Flexbox.
- Estilos modernos con **hover y transiciones** para enlaces y botones.
- Práctica de **secciones** con títulos, párrafos y botones personalizados.
